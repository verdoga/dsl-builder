| Пакет           | Функциональность                                                                                                                                                                      | Границы ответственности                                                                                                                     |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `main`          | Точка входа `cmd/dsl-builder`: связывает компоненты, передаёт версию сборки, запускает приложение.                                                                                    | Только запуск и завершение процесса.                                                                                                        |
| `app`           | Управляет этапами создания, обновления и добавления; хранит состояние операции и принятые решения.                                                                                    | Только последовательность вызовов. Отменяет прежнее подтверждение при изменении плана; предметные правила делегирует.                       |
| `console`       | Последовательный русский диалог: меню, ввод, подтверждения, отмена, вывод диагностики.                                                                                                | Только взаимодействие с пользователем; содержимое превью получает из `preview`.                                                             |
| `preview`       | Формирует текст состава, изменений, причин замены, перечней ID и статистики ресурсов.                                                                                                 | Только представление подготовленных данных; не принимает решения и не читает пользовательский ввод.                                         |
| `diagnostic`    | Единый тип ошибки: код, причина, путь, ID, координаты и связанные файлы.                                                                                                              | Только представление диагностических данных; обнаружение ошибок принадлежит профильным пакетам.                                             |
| `filetree`      | Рекурсивно перечисляет файлы, разрешает и нормализует пути, исключает циклы и повторы, детерминированно сортирует пути.                                                               | Только файловое дерево и идентичность путей; содержимое файлов не разбирает.                                                                |
| `parsed`        | Читает технический JSON в `model.Result`, проверяет UTF-8, снимает начальный BOM; проверяет контракт 1.0, признаки ошибок парсера и связи `parentLine`; строит рабочие индексы строк. | Только загрузка, проверка и подготовка входа. Использует типы `parsed/model`; не дублирует модель, не разбирает DSL и не строит урок.       |
| `parsed/model`  | Существующий пакет `model`: хранение входных данных по `Contract.jsonc` 1.0 в структурах `Result`, `Document`, `Line`, `Element` и связанных типах; JSON-теги и перечисления.         | Только представление данных в памяти, без зависимостей от других пакетов. Чтение, проверки, рабочие индексы и преобразование остаются вне модели. |
| `fragments`     | Разрешает `fragment/include`, создаёт независимые экземпляры включений с сохранением исходных координат.                                                                              | Только развёртывание фрагментов; не назначает итоговые ID и не строит страницы.                                                             |
| `structure`     | Строит страницы и дерево нод: границы `task/step/variant`, размещение инструкций, структурные флаги заданий.                                                                          | Только типы, вложенность и порядок нод; собственные данные и ID не формирует.                                                               |
| `textdata`      | Формирует данные текстовых нод, таблиц, списков слов, `example` и `multifill`; сохраняет нужные переносы и разметку.                                                                  | Только текстовые данные; внутренние ответы `multifill` не извлекает.                                                                        |
| `exercisedata`  | Формирует данные `question`, `singleChoice`, `multipleChoice`, `matching`, `ordering`: коллекции, ответы, связанные подсказки и `checkable`.                                          | Только данные перечисленных упражнений; не размещает ноды в дереве и не обрабатывает `multifill`.                                           |
| `resourcefind`  | Разрешает явные пути и подстроки, ищет медиа и сопутствующие файлы; владеет таблицей расширений/MIME и проверяет неоднозначность.                                                     | Только выбор файлов в разрешённой области; возвращает также перечень учтённых путей, но не читает байты.                                    |
| `resourceembed` | Читает выбранные файлы и формирует медиаданные урока с Base64, именем, MIME и ролью.                                                                                                  | Только встраивание точных байтов; не ищет файлы и не преобразует медиаформаты.                                                              |
| `resourceusage` | Объединяет учтённые пути, отмечает успешное встраивание, возвращает использованные и неиспользованные файлы и счётчики.                                                               | Только учёт ресурсов текущей операции по нормализованным путям; без файлового ввода-вывода.                                                 |
| `convert`       | Выполняет единый конвейер преобразования одного проверенного входа: фрагменты, структура, данные, ресурсы, первичная нумерация, проверка урока.                                       | Только координация преобразования; правила этапов не дублирует, режим работы модуля не выбирает.                                            |
| `lesson`        | Определяет модель урока и проверяет ограничения фиксированной `Lesson.schema.json`, а также уникальность внутренних ID.                                                               | Только контракт одного итогового урока; без преобразования, сравнения и правил ревизии.                                                     |
| `manifest`      | Определяет модель манифеста и проверяет ограничения фиксированной `Manifest.schema.json`.                                                                                             | Только контракт манифеста; не распределяет уроки и не проверяет ссылки на файлы.                                                            |
| `catalog`       | Формирует и редактирует размещение уроков: курс, юнит, секции, веса и порядок; синхронизирует записи с уроками и описывает изменения манифеста.                                       | Владеет синтезом весов, конфликтами внутри групп и запретом смешанного состава. Не меняет содержимое уроков или технические имена.          |
| `order`         | Проверяет запись положительного целого веса и сравнивает числовые значения произвольной длины, сохраняя исходное написание.                                                           | Только арифметика весов; группы, сортировку уроков и конфликты определяет `catalog`.                                                        |
| `identity`      | Проверяет и форматирует ID уроков, страниц, нод и технические имена; разбирает номера и суффиксы, задаёт правила сравнения ID.                                                        | Только синтаксис и сравнение идентификаторов; номера, уникальность и момент смены версии определяют вызывающие пакеты.                      |
| `compare`       | Сравнивает содержимое двух уроков и формирует план отличий: поля, отдельные ноды, замена нод страницы или всего урока.                                                                | Только обнаружение отличий и уровня замены; игнорирует служебные изменения, не меняет модели и ID.                                          |
| `revision`      | Применяет принятый план урока; назначает первичные и обновлённые ID, ревизию, дату и актуальный `lineCount`.                                                                          | Только жизненный цикл версии урока; не определяет отличия, не меняет манифест и не запрашивает подтверждения.                               |
| `module`        | Хранит состав модуля и исходные байты уроков; назначает технические имена, проверяет уникальность ID и соответствие файлов записям и метаданным манифеста.                            | Только состав и связи целого модуля. Проверки уроков, манифеста и размещения вызывает у их владельцев.                                      |
| `moduleio`      | Читает и записывает плоский ZIP и JSON; проверяет записи ZIP, сохраняет байты неизменённых уроков.                                                                                    | Только формат хранения; согласованность модели проверяет через `module`, целевой файл не заменяет.                                          |
| `safewrite`     | Создаёт временный файл рядом с целью, вызывает запись и проверку, безопасно заменяет результат, восстанавливает исходник при сбое и очищает временные файлы.                          | Только файловая транзакция после подтверждения; формат содержимого задают переданные функции записи и проверки.                             |
